K‑Means Clustering

Since K‑Means is unsupervised, we need a dataset with numeric features. A commonly used one is the Iris dataset — small, clean and perfect for clustering.

4.Data Preparation

K‑Means works better on scaled data, so we’ll standardize features:

In [5]:
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

5.Determine Number of Clusters

Though we know iris has 3 species, K‑Means doesn’t. We’ll use the Elbow method:

In [6]:
inertia = []
K = range(1, 11)

for k in K:
    kmeans = KMeans(n_clusters=k, random_state=42)
    kmeans.fit(X_scaled)
    inertia.append(kmeans.inertia_)

plt.plot(K, inertia, 'bo-')
plt.xlabel('Number of clusters')
plt.ylabel('Inertia')
plt.title('Elbow Method for Optimal k')
plt.show()

6.Train K‑Means

In [7]:
kmeans = KMeans(n_clusters=3, random_state=42)
kmeans.fit(X_scaled)

labels = kmeans.labels_
centroids = kmeans.cluster_centers_
